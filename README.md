## 📄 Project Overview
The **Hospital Management System (OOP in Python)** is a console-based project designed to manage patients, doctors, and lab/pharmacy operations.  
It applies **Object-Oriented Programming (OOP)** principles such as classes, inheritance, and encapsulation with file handling for persistent data storage.

---

## 🧩 Features

### 👩‍⚕️ Patient Module
- Register and login  
- Book doctor appointments  
- View doctor perceptions/prescriptions  
- View lab reports  
- Pay medical bills  

### 🧑‍⚕️ Doctor Module
- Secure login  
- View patient appointments  
- Write perceptions/prescriptions  
- Recommend lab tests  
- Logout safely  

### 🧪 Lab / Pharmacy Module
- View test requests from doctors  
- Upload lab test reports  
- View perceptions from doctors  
- Mark medicines as delivered  

---

## 🧠 Concepts Used
- Object-Oriented Programming (OOP)
  - Classes & Objects  
  - Inheritance  
  - Encapsulation  
- File Handling (`open`, `read`, `write`)
- Role-based menu system
- Text-based data storage

## 📂 Project Structure
Hospital_Management_System/
│
├── hospital.py              # Main Python program file
├── patients.txt             # Patient records
├── appointments.txt         # Appointment records
├── perceptions.txt          # Doctor perceptions
├── tests.txt                # Recommended tests
├── reports.txt              # Uploaded lab reports
├── billing.txt              # Billing information
└── README.md                # Documentation file

---

## 💾 Data Storage
All data is stored in text files:
- `patients.txt` → Patient usernames, passwords, names  
- `appointments.txt` → Appointment data  
- `perceptions.txt` → Doctor prescriptions  
- `tests.txt` → Recommended tests  
- `reports.txt` → Lab reports  
- `billing.txt` → Payment details
